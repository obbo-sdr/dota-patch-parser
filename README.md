# Dota Patch Parser

In this project, I have developed a simple parser for the [Official Dota 2 Website (Patch 7.41b)](https://www.dota2.com/patches/7.41b).
Microsoft Edge is required for the program to function correctly (pre-installed on all Windows systems).

## Methods and Tools

The following tools and paradigms were used in this project:
 - **OOP** ([Link to Wiki](https://wikipedia.org))
 - **BeautifulSoup** ([Documentation](https://crummy.com))
 - **Selenium** ([Documentation](https://selenium.dev))

### Future Plans
I plan to implement a feature that allows users to collect data for any specific patch. Additionally, I intend to expand and refine the class hierarchy for better detail and scalability.
